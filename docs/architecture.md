# Architecture

The application is a static React frontend. An optional Python research service binds to 127.0.0.1:8341. No authentication system, database, broker or simulated live sensor service is introduced. It can run on localhost or a static host once publication rights and acceptance gates are cleared.

`src/import.worker.ts` accepts the user's File, reports actual processing phases and returns a normalized dataset. The UI can cancel by terminating the worker. `src/import.ts` validates extensions/MIME, 2 MiB input, ZIP signature and streamed expansion (16 MiB, at most 200 entries), then rejects formula/macro/external-link contents and noncanonical schemas. It parses one sheet with read-excel-file 9.3.12, or parses strict UTF-8 CSV. No formula evaluation or silent imputation occurs. Source row and SHA-256 survive sorting.

`src/domain.ts` is the authoritative application scorer. Pure typed functions compute retrospective median/MAD references, deterministic scores, flags, quality warnings and guarded CSV output. Python remains an independent verification path; the optional research API executes GPR evaluation without replacing the TypeScript scorer.

`src/App.tsx` owns in-memory dataset, per-sensor selection, dialogs and worker lifecycle. URL hash parameters hold route, sensor and threshold for browser back/forward and refresh. Reselecting a route preserves selection and settings. Refresh intentionally discards uploaded measurements and reloads the synthetic example; no source data enters localStorage, IndexedDB or the URL. `src/Chart.tsx` maps actual dates to a continuous time axis; same-date observations remain distinct points and table rows. The source row order breaks display ties without implying intraday chronology.

Native dialog modal behavior is supplemented with explicit Tab wrapping and focus return. Backdrop clicks do not dismiss dialogs; Close or Escape does. One modal is rendered at a time. Chart selection also has an accessible table alternative. CSS adapts the 236 px desktop sidebar to a mobile navigation row. Fonts are bundled locally. No animation or remote fonts are required.

`src/TurbineViewer.tsx` is lazy-loaded inside a scoped error boundary. GLTFLoader decodes the local Meshopt/WebP GLB. Local PBR lighting, shadows, bounded OrbitControls, pointer/touch/keyboard controls and a paused-by-default camera orbit are implemented. DPR is capped at 1.5. Rendering is demand-driven while paused; hidden pages stop orbit. Resize observation, fetch cancellation, material/geometry/texture disposal, ImageBitmap closure, shadow/environment disposal and context release run at teardown. Unsupported WebGL2, corrupt/missing files, decoder failure and context loss expose a retry and an actual-mesh poster. Module failure stays inside the panel. No rotor motion or plant simulation is asserted.

`src/ForecastPanel.tsx` sends measurements only after explicit invocation to `/api/research/forecast`, proxied locally by Vite. `scripts/research_server.py` checks exact Host/Origin, JSON body size and schema; one 60-second subprocess fits five models with pinned Python libraries. Request IDs support cancellation. Requests/results remain in memory and responses are no-store; request bodies are not logged. It supports 12–256 observations, chronological last-eight holdout and rejects a shared-date train/test boundary. Data changes cancel and clear stale results. This endpoint is a localhost research utility, not an authenticated multi-user public API. See ADR 0002.

Build and CI require no private inputs. Public examples and documentation screenshots originate only from `src/demo.ts`, an independently generated synthetic dataset. `.private/` contains local source audit output and restricted visual comparison artifacts and is excluded from all commits.
